# Comparative Performance Analysis of Machine Learning Classification Algorithms Using Scikit-learn

## Problem statement

Implement and compare machine learning classification algorithms on a selected dataset, then identify the algorithm that provides the best classification results using appropriate evaluation metrics.

## Project objective

Part 1 collects, explores, visualizes, and prepares the Breast Cancer Wisconsin (Diagnostic) dataset. Part 2 trains and compares four classifiers on the same reproducible, stratified training and testing data.

## Dataset

The project uses the Breast Cancer Wisconsin (Diagnostic) dataset included with `sklearn.datasets.load_breast_cancer()`. It contains 569 samples, 30 numerical features, and two target classes: `0 = malignant` and `1 = benign`. The data is loaded directly from scikit-learn, so no external CSV download is needed.

## Part 1 features

- Load the dataset into a Pandas feature DataFrame and target Series.
- Report dataset dimensions, feature names, target names, sample rows, statistics, data types, missing values, duplicate rows, class balance, and non-finite values.
- Generate a class distribution chart, representative feature histograms, and a numerical-feature correlation heatmap.
- Validate data quality without silently dropping records or features.
- Split data into stratified training and testing sets (80%/20%, `random_state=42`).
- Fit `StandardScaler` on training features only and retain both scaled and original feature splits.

## Part 2 features

- Train Random Forest, Support Vector Classifier (SVM), Gaussian Naive Bayes, and Gradient Boosting.
- Reuse one train/test split from `preprocessing.py`. SVM uses the training-fitted scaled features; the other models use the original features.
- Report accuracy and malignant-positive precision, recall, and F1-score. Classification reports include both malignant and benign classes.
- Save each model's confusion matrix, a grouped metric comparison chart, a combined confusion-matrix figure, and metrics in CSV format.
- Identify the measured best model by malignant-class F1-score and separately highlight malignant-class recall. This experiment is educational and not intended for clinical use.

## Installation (Windows)

Python 3.10 or later is recommended.

1. Open a terminal in the project folder.
2. Create and activate a virtual environment:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use the Command Prompt activation script instead:

   ```bat
   .venv\Scripts\activate.bat
   ```

3. Install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

4. Run Part 1:

   ```powershell
   python preprocessing.py
   ```

5. Run Part 2:

   ```powershell
   python main.py
   ```

## Train/test split and feature scaling

`train_test_split()` uses `test_size=0.20`, `random_state=42`, and `stratify=y`. This produces 455 training samples and 114 testing samples while preserving class proportions. The `StandardScaler` is fitted only on `X_train`; that fitted scaler transforms both training and testing features. The original, unscaled `X_train` and `X_test` remain available, and target labels are never scaled.

SVM uses the scaled features. Random Forest, Gaussian Naive Bayes, and Gradient Boosting use the original unscaled features. All four models use the same split.

## Generated outputs

- `outputs/dataset_summary.txt` — dataset description, structure, data-quality checks, descriptive statistics, class counts, and split/scaling details.
- `outputs/class_distribution.png` — malignant and benign sample counts.
- `outputs/feature_distributions.png` — readable histograms for three representative features by diagnosis.
- `outputs/correlation_heatmap.png` — correlations among the numerical features.

Figures are saved at 300 DPI. No classifier is trained in Part 1.

## Part 2 outputs

- `outputs/comparison_results.csv` — accuracy, malignant-positive precision/recall/F1, and benign-class precision/recall/F1 for each classifier.
- `outputs/<model>_confusion_matrix.png` — separate labeled confusion matrix for each classifier.
- `graphs/model_comparison.png` — grouped comparison of accuracy and malignant-positive metrics.
- `graphs/confusion_matrices.png` — combined view of all four confusion matrices.

The positive class for precision, recall, and F1-score is explicitly **malignant (label 0)**. The best model is selected from the measured malignant-class F1-scores, and the highest malignant-class recall is also reported.
